# Reference images

Theory diagrams shown at the top of each lab page. One folder per topic:

```
references/
  idempotency/     ← shown on /labs/inventory/idempotency
  <topic>/
```

Drop any `.png .jpg .jpeg .webp .gif .svg` into the topic folder — the page picks it up
automatically (sorted by file name, so prefix `01-`, `02-` to control order). No code change.
